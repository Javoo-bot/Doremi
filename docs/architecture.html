The pull request is the gate

  1. Agent opens agent/… branch
  2. First commit is the plan, alone
  3. Code commits
  4. plan-gate + risk-tier
  5. Required checks
  6. Auto-merge, or wait for you

The plan commit lets anyone see what the agent meant to do before seeing what it did. A check that fails once sends the agent back to fix its branch. A second failure opens an issue on the Project board with what failed, what was tried, the evidence, and a suggested next step.

Guardrails, most important first

  1. Agents push only to agent/*. main needs a PR and green checks.
  2. plan-gate is a required check, so the forbidden paths are enforced by the system, not by instructions.
  3. The Cloudflare token lives only in the production environment, which waits for your approval.
  4. The Worker stops calling the LLM at €50 a week and warns at €35.
  5. A hook blocks deploys, force-pushes, recursive deletes and any MCP server not on the allowlist before they run.
  6. Every tool call, check and LLM call leaves a record tied to a run ID and a commit.
  7. The repo is public, so nothing secret can merge. gitleaks scans every commit before you commit and again as a required check before merge. Fork PRs never see a secret, and your recordings never enter the repo.
